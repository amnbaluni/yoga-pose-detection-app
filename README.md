# Yoga Pose Detection App

A React + Vite web application for AI-powered yoga pose detection and tracking.

## Features

- Real-time webcam pose detection
- AI-powered form correction
- Progress tracking and analytics
- Multiple yoga style categories
- Responsive design with Tailwind CSS

## Tech Stack

- React 19
- Vite
- TypeScript
- Tailwind CSS v4
- shadcn/ui components
- Prisma (SQLite)

## Getting Started

```bash
bun install
bun run dev
```
